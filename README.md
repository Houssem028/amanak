# أمانك — Amank 🇹🇳

نموذج أولي مجاني (Beta) لفكرة تطبيق أمان شخصي: بدء رحلة، مشاركة الموقع، شخص موثوق، GPS، حالة الاتصال، وآخر موقع معروف.

## تشغيل سريع

يمكن فتح `index.html` مباشرة للتجربة، لكن **GPS وPWA يحتاجان HTTPS أو localhost** في معظم المتصفحات.

### GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى المستودع (ارفع الملفات نفسها، وليس مجلدًا مضاعفًا داخل المستودع).
3. من **Settings → Pages** اختر النشر من فرع `main` ومجلد `/root`.
4. افتح رابط GitHub Pages من هاتفك.
5. اسمح للموقع باستخدام الموقع.
6. من متصفح الهاتف اختر **إضافة إلى الشاشة الرئيسية / Install app**.

## ما تعمل عليه النسخة الحالية؟
- واجهة Mobile-first.
- GPS عبر `navigator.geolocation.watchPosition`.
- خريطة OpenStreetMap عبر Leaflet CDN.
- بدء/إنهاء رحلة.
- حفظ آخر موقع معروف محليًا.
- كشف online/offline.
- مشاركة معلومات الرحلة عبر Web Share أو نسخها.
- زر SOS تجريبي فقط.
- PWA + Service Worker.

## ما ليس موجودًا بعد؟
هذه ليست نسخة إنتاجية ولا يوجد Backend حقيقي. لذلك **لا يوجد حتى الآن تتبع حي بين هاتفين** ولا إرسال SOS حقيقي ولا إرسال SMS تلقائي عند انقطاع الإنترنت.

## الخطوة التالية
إضافة Backend مجاني/منخفض التكلفة لعمل:
- غرفة رحلة برمز/رابط.
- مشاهدة الموقع مباشرة من هاتف آخر.
- تحديثات الموقع في الوقت الحقيقي.
- حسابات المستخدمين.
- جهات موثوقة.
- تنبيهات حقيقية.

> لا تعتمد على هذه النسخة وحدها في حالات الطوارئ. هي Prototype لإثبات الفكرة.

## ملاحظة الخرائط
الخريطة تستخدم OpenStreetMap وLeaflet. يجب إبقاء الإسناد الظاهر في الخريطة واحترام سياسات استخدام مزود الخرائط عند الانتقال إلى مستخدمين كثر.
